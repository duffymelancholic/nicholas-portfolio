# Nicholas Obonyo Abala — Portfolio

Personal portfolio site for **Nicholas Obonyo Abala**, Full-Stack & AI Developer.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

```bash
npm run build
npm start
```

Or deploy to Vercel from this directory.
